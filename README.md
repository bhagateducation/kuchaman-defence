# Kuchaman Defence Academy website

A responsive, dependency-free website prototype built with HTML, CSS, and JavaScript.

## Run locally

From this directory, run `python3 -m http.server 8000`, then open `http://localhost:8000/`.

## Content to verify before publication

The source Elementor site was inaccessible from the cloud environment during implementation. The copy is intentionally general, the mark is a temporary text logo, and the hero is a generated image. Confirm the actual page structure, brand assets, course offerings, admissions details, and contact information against the live site before publishing this as its replacement.
